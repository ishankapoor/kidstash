# Kid's Stash

A static, mobile-friendly money tracker for Shanaya and Vidar.

## GitHub Pages

This site is intentionally plain HTML, CSS, and JavaScript, so GitHub Pages can serve it directly from the `gh-pages` branch. No GitHub Actions workflow is required.

To enable it once in the repository:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `gh-pages` and the `/ (root)` folder, then save.

Future pushes to `gh-pages` will be published automatically. Update the hard-coded entries in `script.js` when the kids' ledger changes.
